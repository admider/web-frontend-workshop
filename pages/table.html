3. 经典场景：使用 Table 语义标签进行网页布局

在 CSS Flexbox 普及之前，开发者常利用 <thead>（头部）、<tbody>（主体内容）、<tfoot>（底部）来划分网页的区域。为了让两侧的导航和内容并排，他们还会在 <tbody> 里嵌套左右两个 <td>。
