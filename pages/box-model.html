1. 认识盒子模型

每个 HTML 元素都被看作一个矩形盒子。盒子模型由 内容（content）、 内边距（padding）、边框（border）、 外边距（margin） 组成。理解这四层结构是掌握 CSS 布局的基础。

💡 类比：手机盒子 —— 手机是内容，内衬是内边距，纸盒是边框，盒子之间的间距是外边距

2. <div> 标签

<div> 是 HTML 提供的块容器标签，用于划分网页模块。 HTML5 新增了语义化标签 <header> <nav> <section> <article> <aside> <footer>。

5. 外边距 margin

外边距是元素边框与相邻元素之间的距离。与 padding 不同，margin 允许负值。 常用 margin: 0 auto 实现块级元素水平居中。 重点：当两个相邻元素都设置了 margin 时，它们之间的距离取较大值，而不是相加。

6. 盒子的宽与高

width 和 height 的含义取决于 box-sizing： content-box（默认）下 width/height 只作用于内容区， padding 和 border 会往外撑开，整体盒子尺寸变大； border-box 下 width/height 是内容 + padding + border 的总和， 整体尺寸锁定，padding 和 border 的厚度不变，内容区被压缩或撑大。 无论哪种模式，元素实际占用的总宽高都还要再加上 margin。

💡 观察要点：
· content-box：拖动 width 时，content 区变化，padding 和 border 的厚度不变， 但它们会被 content 往外撑开，整体橙框变大或变小。
· border-box：拖动 width 时，橙框整体尺寸严格等于 width， padding 和 border 的厚度不变，但 content 区被压缩或撑大。
· 无论哪种模式，元素实际占用的总宽高都要再加上 margin × 2。

7. 背景属性 background

背景图片和背景颜色占据 content + padding 区域， 不包含 border 和 margin。可以设置图片的平铺方式、位置、大小和固定方式。
